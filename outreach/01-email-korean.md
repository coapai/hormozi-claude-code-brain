## 메일 1 — 첫 접촉 (시안 첨부)

**제목:** `[제품명] 숏폼 광고 시안 만들어 봤습니다 (10초, CGI)`

```
안녕하세요, [브랜드명] 마케팅 담당자님.

서울에서 CGI·AI 광고 영상을 제작하는 [이름]입니다.
AGE20'S, 한스킨, 오로트, 아렌시아 브랜드의 숏폼 광고 소재를 작업했습니다.

이번에 나온 [제품명] 패키지가 CGI로 표현했을 때 특히 잘 나올 것 같아
먼저 10초짜리 시안을 만들어 봤습니다.

▶ 시안 보기: [링크]

기획서나 브리프 없이 제 해석으로만 만든 거라
방향만 알려주시면 브랜드 톤에 맞춰 다시 작업해 드리겠습니다.

정식 버전은 15~20초, 4K로 제작하며 수정 2회 포함,
작업 기간은 영업일 기준 5일입니다.

혹시 이번 분기에 준비 중이신 캠페인이 있으실까요?

포트폴리오: [인스타그램 링크]

감사합니다.

[이름] 드림
[이메일] / 카카오톡 ID: [아이디]
```

> **참고:** 시안 영상의 사용 권리는 계약 전까지 양도되지 않습니다.
> 이 문장은 메일 본문에 굳이 쓰지 말고, 상대가 "그냥 이거 쓰면 안 되나요?"
> 라고 물을 때만 부드럽게 안내하세요.

## DM 즉시 응답 스크립트 (인스타그램)

브랜드가 DM을 보내면 **5분 안에** 답장. 가격부터 말하지 마세요.

```
안녕하세요! 연락 주셔서 감사합니다.
마침 [제품명] 보고 있었는데 반갑네요.

정확한 견적 드리려면 두 가지만 여쭐게요.

1. 어떤 제품 / 어떤 캠페인인가요?
2. 어디에 쓰실 예정인가요? (인스타 오가닉 / 유료 광고 / 매장 스크린)

알려주시면 그에 맞는 구성으로 바로 정리해 드리겠습니다.
```

## "얼마예요?" 라고 물었을 때

가격표를 던지지 마세요. 두 개만 말하고, 하나를 추천하세요.

```
사용처 기준으로 보통 이렇게 나갑니다.

· 캠페인 패키지 — 15~20초 4K 영상 4편, 통일된 아트디렉션,
  편당 수정 2회, 12개월 독점 사용권, 원본 파일 포함 — 400만원

· 단일 Hero 영상 — 15~20초 4K 1편, 수정 2회,
  오가닉 + 유료 광고 6개월 사용권 — 80만원

처음 진행하시는 경우 대부분 Hero 한 편으로 시작하시고,
반응 보고 패키지로 넘어가십니다.

[제품명]이면 Hero 쪽이 맞을 것 같은데, 어떠세요?
```

## "너무 비싼데요" 라고 했을 때

**절대 그 자리에서 가격을 깎지 마세요.** 범위를 줄이세요.
(Closing Rule #11)

```
네, 이해합니다. 예산 안에서 맞춰 보겠습니다.

두 가지 방법이 있는데요.

1. 6~10초 단일 컷으로 줄이면 45만원입니다.
   피드나 스토리용으로는 충분합니다.

2. 사용 범위를 오가닉으로만 한정하면 Hero 영상을
   조금 조정할 수 있습니다.

어느 쪽이 더 편하실까요?
```

## 톤 체크리스트

- [ ] 존댓말, 담당자님 호칭 (이름을 알면 이름 사용)
- [ ] 제목에 제품명이 들어갔는가
- [ ] 본문 200자 이내로 읽히는가 (모바일에서 읽습니다)
- [ ] 시안 링크가 메일 상단 1/3 안에 있는가
- [ ] 가격이 첫 메일에 없는가
- [ ] 마지막이 질문 하나로 끝나는가
- [ ] "기회를 주시면", "부족하지만" 같은 표현이 없는가
- [ ] 대용량 파일 첨부 대신 링크를 썼는가
