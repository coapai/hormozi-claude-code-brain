## 메일 1 — 첫 접촉 (시안 첨부)

**제목:** `[제품명] 숏폼 광고 시안 만들어 봤습니다 (10초, CGI)`

```
안녕하세요, [브랜드명] 마케팅 담당자님.

서울에서 CGI·AI 광고 영상을 제작하는 [이름]입니다.
AGE20'S, 한스킨, 오로트, 아렌시아 브랜드의 숏폼 광고 소재를 작업했습니다.

이번에 나온 [제품명] 패키지가 CGI로 표현했을 때 특히 잘 나올 것 같아
먼저 10초짜리 시안을 만들어 봤습니다.

▶ 시안 보기: [링크]

기획서나 브리프 없이 제 해석으로만 만든 거라
방향만 알려주시면 브랜드 톤에 맞춰 다시 작업해 드리겠습니다.

정식 버전은 20초 이내, 4K로 제작하며 수정 2회 포함,
작업 기간은 영업일 기준 5일입니다.

혹시 이번 분기에 준비 중이신 캠페인이 있으실까요?

포트폴리오: [인스타그램 링크]

감사합니다.

[이름] 드림
[이메일] / 카카오톡 ID: [아이디]
```

> **참고:** 시안 영상의 사용 권리는 계약 전까지 양도되지 않습니다.

## DM 즉시 응답 스크립트 (인스타그램)

브랜드가 DM을 보내면 **5분 안에** 답장. 가격부터 말하지 마세요.

```
안녕하세요! 연락 주셔서 감사합니다.
마침 [제품명] 보고 있었는데 반갑네요.

정확한 견적 드리려면 두 가지만 여쭐게요.

1. 어떤 제품 / 어떤 캠페인인가요?
2. 어디에 쓰실 예정인가요? (인스타 오가닉 / 유료 광고 / 매장 스크린)

알려주시면 그에 맞는 구성으로 바로 정리해 드리겠습니다.
```

## "얼마예요?" 라고 물었을 때

가격표를 던지지 마세요. 두 개만 말하고, 하나를 추천하세요.
비싼 것부터 말합니다.

```
사용처 기준으로 보통 이렇게 나갑니다.

· 3편 패키지 — 20초 이내 4K 영상 3편, 통일된 아트디렉션,
  편당 수정 2회 — 150만원

· 단일 Hero 영상 — 20초 이내 4K 1편, 수정 2회 — 60만원

작업 기간은 영업일 기준 5일, 계약금 50% / 잔금 50%입니다.

처음 진행하시는 경우 대부분 Hero 한 편으로 시작하시고,
반응 보고 패키지로 넘어가십니다.

[제품명]이면 Hero 쪽이 맞을 것 같은데, 어떠세요?
```

> 유료 광고나 매장 스크린에 쓰신다고 하면 사용권 조건이 달라집니다.
> 그래서 견적 전에 "어디에 쓰실 예정인가요"를 먼저 묻습니다.

## "너무 비싼데요" 라고 했을 때

**절대 그 자리에서 가격만 깎지 마세요.** 범위를 줄이거나, 교환하세요.
(Closing Rule #11)

**방법 1 — 범위 축소**

```
네, 이해합니다. 예산 안에서 맞춰 보겠습니다.

길이를 10초 이내 단일 컷으로 줄이면 40만원입니다.
피드나 스토리용으로는 충분합니다.

어느 쪽이 더 편하실까요?
```

**방법 2 — 교환 (여기서만 50만원이 나옵니다)**

이게 핵심입니다. 가격을 그냥 내리는 게 아니라, 없는 걸 받아옵니다.

```
그럼 이렇게 하시는 건 어떠실까요.

50만원에 진행해 드리겠습니다. 대신 두 가지만 부탁드릴게요.

1. 결과가 만족스러우시면 짧게 후기 한 줄과
   포트폴리오에 브랜드명을 쓸 수 있도록 허락해 주시는 것
2. 게시 후 2~3주 뒤에 성과 수치(저장수나 CTR 정도)를
   공유해 주시는 것

이 조건이면 50만원에 맞춰 드릴 수 있습니다. 괜찮으실까요?
```

10만원을 내주고, 돈보다 부족한 것(증거)을 받아옵니다.
lesson04의 스크립트를 그대로 옮긴 구조입니다.

**방법 3 — 작게 시작**

```
컨셉 단계까지 먼저 진행해 보시는 건 어떠세요?

컨셉 2안 + 스토리보드까지 20만원이고,
이어서 제작 진행하시면 그 금액은 본 제작비에서 차감해 드립니다.
```

## 조건 안내 (견적서에 붙이는 문구)

```
· 작업 기간: 영업일 기준 5일 (스토리보드 확정 후)
· 수정: 2회 포함, 시안 전달 후 7일 이내
· 스토리보드 확정 후 방향 전환은 별도 건으로 진행됩니다
· 계약금 50% / 잔금 50%, 최종 4K 파일은 잔금 확인 후 전달
· 사용 범위: 브랜드 공식 계정 오가닉 게시
  (유료 광고 / 매장 스크린 사용은 별도 협의)
· 게시 30일 후 포트폴리오 사용에 대해 미리 양해 부탁드립니다
```
